# Security Policy

## Reporting a Vulnerability

Report vulnerabilities affecting the V7 fork through this repository's
private vulnerability reporting feature in the Security tab. Do not include
proofs of concept, credentials, or internal deployment details in public issues.

For vulnerabilities affecting upstream Tailscale without any fork-specific
changes, follow the upstream project's security policy. If you are unsure
whether a vulnerability is specific to this fork, report it privately here
and V7 will coordinate with upstream as needed.
